# Checkpoint 2 results: mixed / not

Model-dependent artifacts are generated by
`../../notebooks/checkpoint2/<dataset>/01_build_artifacts.ipynb` under `<dataset>/artifacts/<model_name>/`.
The offline notebook adds `ccs_probes.npz` there and exports scores and metrics
to `<dataset>/analysis/<run_name>/<model_name>/`.

The MIXED five-model run completed on 2026-09-10 (Asia/Yakutsk), covering 1244
statements, 165 model/layer combinations and 205260 score rows. All five model
directories contain raw artifacts and trained CCS probes. CUDA was used;
the 9B models retained their original dtype with partial CPU weight offload.

`mixed/analysis/checkpoint1_compatible/all_layer_metrics.csv` combines all layers;
`model_summary.csv` contains the model-level summary. `validation.json` records
successful cache validation and CPU restoration of all saved probes without
model loading or CCS retraining. Restored latent scores differ from their CUDA
exports by less than 8.4e-7. Git confirms that tracked Checkpoint 1 notebooks,
results and reference code have no changes relative to HEAD.

See `<dataset>/logs/run_status.json` for stage completion and the Checkpoint 2 notebook
README for the cache contract, experimental semantics and usage.

NOT uses the same five models and methodology with 1250 statements. Its independent
artifacts, analysis and logs live under `not/`; completion is recorded by its runner.
The existing MIXED binary artifacts and CSVs were moved without recomputation;
`migration_mixed.json` records SHA-256 verification. Only dataset provenance was
added to the five MIXED metadata files. See the notebook README for exact commands.
