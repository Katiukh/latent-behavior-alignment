# Checkpoint 2 results

Model-dependent artifacts are generated by
`../../notebooks/checkpoint2/01_build_artifacts.ipynb` under `artifacts/<model_name>/`.
The offline notebook adds `ccs_probes.npz` there and exports scores and metrics
to `analysis/<run_name>/<model_name>/`.

The full five-model run completed on 2026-09-10 (Asia/Yakutsk), covering 1244
statements, 165 model/layer combinations and 205260 score rows. All five model
directories contain raw artifacts and trained CCS probes. CUDA was used;
the 9B models retained their original dtype with partial CPU weight offload.

`analysis/checkpoint1_compatible/all_layer_metrics.csv` combines all layers;
`model_summary.csv` contains the model-level summary. `validation.json` records
successful cache validation and CPU restoration of all saved probes without
model loading or CCS retraining. Restored latent scores differ from their CUDA
exports by less than 8.4e-7. Git confirms that tracked Checkpoint 1 notebooks,
results and reference code have no changes relative to HEAD.

See `logs/run_status.json` for stage completion and the Checkpoint 2 notebook
README for the cache contract, experimental semantics and usage.
